03 — lab

      

        
Built to run in a container.

        

          

            This portfolio runs on Omarchy Linux and is served by Nginx inside a Docker
            container. A bind mount connects this project folder on the host to
            /usr/share/nginx/html in the container, read-only — so an edit
            here appears on refresh, without rebuilding the image.
          

          
Status: live on port 8080.

          
docker run -d --name my-website -p 8080:80 -v "$PWD":/usr/share/nginx/html:ro nginx
